# Fitoholic Raw — Website 1 (Dark Raw)

Demo website for **Fitoholic Raw | Jayesh Patole** ([@fitoholic_rawgym](https://www.instagram.com/fitoholic_rawgym/)) — Thane's calisthenics x yoga studio.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Files
- `index.html` — page markup
- `style.css` — styles
- `script.js` — interactions (membership sign-up, BMI calculator, trial booking, admin dashboard)
- `*.jpg` — images (kept next to the code, no folders)

## Run locally
Open `index.html` in any browser.

## Publish on GitHub Pages
1. Create a new GitHub repository and upload all files from this folder (drag and drop works).
2. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

## Admin demo login
Click "Staff login" in the footer — username **admin**, password **raw@2026**.

Data is saved in the browser (localStorage) for demo purposes only.

## Admin portal
Open `admin.html` (also linked as "Admin Portal" in the site navigation and footer).
It leads to the staff login and dashboard (members, enquiries/leads, payments, reports).
